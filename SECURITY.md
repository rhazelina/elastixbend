# Security Policy

## Supported versions

Only the latest published version receives security fixes.

| Version | Supported |
| ------- | --------- |
| 0.4.x   | Yes       |
| < 0.4   | No        |

## Reporting a vulnerability

Please do not open a public issue. Report privately through
[GitHub private vulnerability reporting](https://github.com/rhazelina/elastixbend/security/advisories/new).

Include the affected version, reproduction steps, and impact. I aim to
acknowledge reports within 3 business days and publish a fix as soon as
practical. Credit is given in the advisory unless you prefer otherwise.
